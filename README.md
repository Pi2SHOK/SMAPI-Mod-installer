# SMAPI Mod Installer

[![Лицензия: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Небольшое оконное приложение для установки модов Stardew Valley в папки `Mods` и
`Mods_…`. Интерфейс написан на Python и PySide6.

## Возможности

- При первом запуске ищет Stardew Valley в стандартных библиотеках Steam,
  предлагает подтвердить найденный путь или выбрать папку вручную.
- Сохраняет путь к игре; его можно изменить в настройках.
- Принимает ZIP-архивы через кнопку выбора файлов и ZIP-архивы или папки модов
  перетаскиванием.
- Позволяет убрать лишние элементы из очереди установки, не удаляя исходные файлы
  с диска.
- Показывает папки `Mods` и `Mods_…`, найденные непосредственно в папке игры,
  и позволяет отметить несколько папок назначения.
- Устанавливает в фоновом потоке, показывает ход работы и сообщает об ошибках
  в отдельном окне.
- При замене обновляет только одноимённую папку мода; остальные папки модов
  не затрагиваются.

Для распознавания модов в папке или ZIP требуется `manifest.json`. Если
одноимённая папка назначения уже существует, она заменяется только если в ней
также есть `manifest.json`.

## Запуск из исходников (Windows)

Нужен Python 3.10 или новее. В PowerShell из корня репозитория установите
зависимости:

```powershell
py -m pip install -r requirements.txt
py installer.py
```

Если используете виртуальное окружение проекта и PowerShell блокирует
`Activate.ps1`, активировать его не обязательно — запустите Python напрямую:

```powershell
& ".\.venv\Scripts\python.exe" -m pip install -r .\requirements.txt
& ".\.venv\Scripts\python.exe" .\installer.py
```

## Сборка EXE

Установите зависимости (включая PyInstaller), затем из корня проекта запустите:

```powershell
py exe_builder\build.py
```

Скрипт предложит выбрать профиль `main` или `unstable`, соберёт оконный
`installer.exe` и создаст папку с лицензией и ZIP-архив в `dist`:

- `dist\SMAPI-mod-preloader-main\` и `dist\SMAPI-mod-preloader-main.zip`, либо
- `dist\SMAPI-mod-preloader-unstable\` и
  `dist\SMAPI-mod-preloader-unstable.zip`.

## Использование

1. Подтвердите или укажите папку Stardew Valley. В ней должен находиться
   `Stardew Valley.exe`.
2. Перетащите ZIP/папку мода в окно или выберите ZIP кнопкой
   **«Выбрать файлы вручную»**.
3. При необходимости нажмите **«Изменить выбор»**, отметьте ненужные элементы
   и уберите их из очереди. Исходные файлы при этом не удаляются.
4. Нажмите **«Продолжить»**, отметьте одну или несколько папок назначения
   `Mods`/`Mods_…` и подтвердите выбор.
5. После успешной установки нажмите **«Завершить»**, чтобы очистить экран и
   добавить следующую партию модов.

## Безопасность и ограничения

- Установщик не устанавливает SMAPI — он только показывает, найден ли SMAPI
  в выбранной папке игры.
- Проверяйте выбранные папки игры и назначения перед установкой.
- При замене существующей версии мода старые файлы внутри именно этой папки
  удаляются вместе с заменяемой версией; другие моды не удаляются.
- ZIP-архивы с небезопасными путями или символическими ссылками отклоняются.
- Настройки приложения сохраняются средствами `QSettings` в профиле пользователя
  Windows.
